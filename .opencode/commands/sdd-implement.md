# /sdd-implement

Implementa ÚNICAMENTE la tarea indicada de `specs/$1/tasks.md`.
Reglas:
1. Enfoque TDD: Primero tests en rojo para funciones de negocio.
2. Escribe el código mínimo necesario para pasar los tests.
3. Corre la suite de tests (`npm test` o similar).
4. Si pasa, marca el checkbox en `tasks.md` y DETENTE para pedir revisión.
