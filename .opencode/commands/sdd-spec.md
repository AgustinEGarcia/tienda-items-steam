# /sdd-spec

Entrevistame paso a paso para generar o refinar la especificación técnica en `specs/$1/spec.md`.
Asegúrate de:
1. Usar sintaxis EARS formal (CUANDO, SI... ENTONCES, MIENTRAS, EL SISTEMA).
2. Especificar casos límite y vectores de ataque o fallas.
3. Detallar requisitos de seguridad y no funcionales.
4. No pasar a la fase de plan hasta que la spec esté aprobada.
