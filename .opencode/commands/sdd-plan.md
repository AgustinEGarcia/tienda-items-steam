# /sdd-plan

Diseña la arquitectura técnica y el plan de implementación para `specs/$1/plan.md`.
Incluye:
1. Funciones puras y lógica aislada a testear.
2. Contratos de API / endpoints y esquemas de base de datos.
3. Componentes de UI y gestión de estado.
4. Medidas de seguridad y prevención de fallos.
⚠️ No escribas código hasta que el plan esté aprobado.
